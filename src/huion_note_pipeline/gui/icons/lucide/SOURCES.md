# Lucide icons

Downloaded from the official lucide-icons/lucide repository, pinned to:
`1fae58d0a9c661a338036838caf3399b5507bab6`.

Source: https://github.com/lucide-icons/lucide/tree/1fae58d0a9c661a338036838caf3399b5507bab6/icons

The original SVG files are unchanged. `check-white.svg` is a copy of
`check.svg` with only the stroke colour changed to white for checked controls.
No icon geometry has been authored or modified.

The upstream license (ISC and the MIT notice for Feather-derived icons) is
included in `LICENSE`. Assets are bundled locally; the app makes no network
requests to load icons.
